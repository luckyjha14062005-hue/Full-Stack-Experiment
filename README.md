# Web Development Lab Experiments

This repository contains runnable source code for all 13 lab experiments.

## Quick start
- Experiments 1–7: open each `index.html` in a browser. Internet is needed for remote images and APIs in experiments 2, 6 and 7.
- Experiments 8–12: install Node.js, open that experiment's folder in a terminal, run `npm install`, then `npm start`.
- Experiment 11 additionally needs MongoDB running; set `MONGO_URI` in `.env` (copy `.env.example`).
- Experiment 13: `cd 13-react-portfolio`, run `npm install`, then `npm run dev`.

Each folder has its own README with run steps. E-commerce is a learning demo: checkout records a demo order only and does not collect payment information or charge money.
